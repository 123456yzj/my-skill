# 视觉语义与状态要求

优先沿用目标项目主题、组件和设计令牌。需求说明记录视觉职责、层级和验收要求，具体样式语法与实现由前端决定。

## 颜色职责

| 职责 | 设计要求 | 验收关注 |
| :--- | :--- | :--- |
| 画布与表面 | 使用项目背景与分组语义 | 对象归属可辨，重复外壳不增加负担 |
| 正文与辅助文字 | 使用项目字阶与文字语义 | 实际背景上可读，辅助信息不靠过低对比度隐藏 |
| 必要边界 | 按对象、控件和行列误读风险决定 | 编辑范围及行列定位明确 |
| 操作与选中 | 沿用品牌与选中语义 | 与异常含义不同，有非颜色线索 |
| 成功、警告、错误 | 对应真实状态并辅以文字/图形 | 用户能判断结果及下一步 |
| 数据图例 | 分类可辨，图例有名称 | 必要曲线或区域使用线型/标注辅助 |

普通文本对比度至少 4.5:1，大文本至少 3:1；必要控件边界与图形对象至少 3:1。按实际背景与叠加效果核对，禁用和装饰内容按用途判断。项目有更严格要求时遵循项目标准。

## 文字、数值与密度

- 采用项目字阶与真实内容，不固定字号数量或统一使用等宽字体。
- 需要比较的数值说明单位、精度、对齐和格式；标识符保持原义。
- 按任务与设备选择标准或紧凑密度，保留标签、错误与可操作入口。
- 小屏优先重排，必要时提供可访问的展开或滚动方式，不仅缩小文字。
- 长名称、缩放、地区格式和完整文本入口列入相关验收场景。

## 状态与主题

根据实际功能说明默认、焦点、选中、禁用、错误、加载及保存反馈。悬浮可辅助发现，必要信息与操作也应支持键盘和触屏。

仅为目标项目支持的主题提出适配要求。需要动效时说明目的与状态变化，遵循项目动效规范及减少动态效果偏好。
