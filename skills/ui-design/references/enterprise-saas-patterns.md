# 企业业务工作台模式参考

基于常见企业 SaaS 场景整理的候选模式，不作为固定布局或业务能力要求。

## 可借鉴的模式

- 多对象快速处理可使用主从面板，跨项比较可能需要并列或网格。
- 长任务可保持必要状态与主要操作可达，但不遮挡错误和焦点。
- 批量操作写清选中范围、权限、后果、部分失败与恢复。
- 常用操作直显；低频操作可收敛，但保留发现与键盘/触屏访问。
- 历史和审计需求有实际契约时提供对应入口，不假定版本、发布或撤销能力。

## 选择条件

适合高频操作、多组织权限与复杂记录管理。密度、确认行为和编辑载体按任务决定，简单功能只采用必要部分。

采用后将范围、状态、反馈与验收要求写入当前功能条目。
