# 财务与数据工作台参考

借鉴 Stripe 类数据界面的对齐、明细和状态表达。这是模式总结，不是官方规范；具体表现依据项目主题和业务契约。

## 可借鉴的模式

- 金额和比率按真实单位、精度与比较方式对齐，零与缺失值区分。
- 普通列表可弱化边界，矩阵或易串行内容保留必要分隔。
- 详情规模适中且需保留列表上下文时可用抽屉；长任务或跨项比较另选载体。
- 内部标识需要复制时提供键盘、指针与触屏均可访问的入口。
- 业务状态用文字和必要颜色表达，避免选中与异常混淆。

## 选择条件

适合交易、财务与复杂明细任务。抽屉宽度、字体、密度和返回行为由真实内容与设备决定，不固定样式类或尺寸。

采用后把查询、明细、复制和返回要求纳入功能及验收场景。
