# 高频任务工具的交互参考

借鉴 Linear 类任务工具中的操作模式，作为设计候选。这是模式总结，不是官方规范；具体要求以项目和用户任务为准。

## 可借鉴的模式

- 高频操作提供快捷键，同时保留可发现的点击与触屏入口。
- 命令面板适用于用户熟悉的检索或操作，不代替必要按钮。
- 减少重复外壳，保留对象归属、编辑范围与状态语义。
- 乐观反馈仅适用于后果可控、有明确失败恢复且业务允许的操作。

## 选择条件

适合高频条目处理与快速切换任务。新手、审批或高风险操作需明确入口和确认依据。不要预设单色、布局比例、固定延迟或所有操作采用乐观更新。

采用后把入口、触发、失败恢复与验收要求写入对应功能。
