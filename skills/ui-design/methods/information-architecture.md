# 信息组织与可见性

决定用户在完成任务时需要看见什么、比较什么、在哪里执行操作。展示层次不改变数据、权限或提交契约。

## 判断依据

- 当前任务必需的信息、遗漏风险及对象识别。
- 高频与低频任务的实际证据，不假定固定比例。
- 跨项比较是否需要信息同时可见。
- 页面规模、定位需求、设备空间和输入方式。

## 组织方法

1. 按实体和用户任务分组，保持身份、状态及操作归属清楚。
2. 必要信息默认可见；一次只需要一项的短明细可就近展开；长任务或独立审计内容选择合适区域。
3. Primary、Secondary、Advanced 可用于复杂任务分析，不要求所有页面完整分级。
4. 主次操作依据使用频率、后果与误操作风险安排，不固定为一个按钮。必要操作在键盘与触屏下仍可发现。
5. 导航、过滤、分页和定位按真实规模选择，明确返回和刷新后的上下文。
